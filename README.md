# Sales Data Analysis Using Python

## Project Overview
This project analyzes sales data using Python to understand business performance and sales trends.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- CSV Dataset
- Visual Studio Code

## Project Objectives
- Calculate total revenue.
- Calculate total orders.
- Find average order value.
- Identify best-selling products.
- Analyze monthly revenue.
- Visualize sales performance using charts.

## Project Files
- `sales_analysis.py` – Python analysis code.
- `sales_data.csv` – Sales dataset.
- `monthly_sales.png` – Monthly sales chart.
- `requirements.txt` – Required Python libraries.

## How to Run
1. Install Python.
2. Install libraries using `pip install -r requirements.txt`.
3. Run `python sales_analysis.py`.

## Output
The project generates sales summaries and a monthly revenue chart.

## Conclusion
This project demonstrates basic data analysis skills using Python, Pandas, and Matplotlib.
